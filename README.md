# 🎡 사다리 타기 게임 (Ladder Game)

React와 SVG를 활용하여 제작된 인터랙티브 사다리 타기 게임입니다.

## 주요 기능
- **인원 설정**: 2명에서 12명까지 자유롭게 인원 조절 가능.
- **커스텀 입력**: 플레이어 이름과 도착 지점의 결과(당첨, 꽝 등)를 직접 편집 가능.
- **실시간 애니메이션**: 이름을 클릭하면 경로를 따라 이동하는 생동감 있는 효과 제공.
- **모두 보기**: 한 번의 클릭으로 모든 결과를 동시에 확인 가능.
- **결과 요약**: 모든 게임 결과가 하단에 보기 좋게 정리되어 표시됨.

## 시작하기

### 1. 의존성 설치
```bash
npm install
```

### 2. 로컬에서 실행
```bash
npm run dev
```

### 3. 빌드 및 배포 (GitHub Pages)
GitHub에 코드를 푸시한 후 아래 명령어를 실행하여 배포할 수 있습니다.
```bash
npm run deploy
```
*주의: `vite.config.ts`의 `base` 설정이 `./`로 되어 있어 어떤 레포지토리 경로에서도 잘 작동합니다.*

## 프로젝트 구조
- `App.tsx`: 메인 게임 화면 및 UI 구성.
- `ladderLogic.ts`: 사다리 생성 및 경로 계산 핵심 로직.
- `styles.css`: 모던한 디자인과 애니메이션 스타일.
- `main.tsx`: React 앱 진입점.

## 테스트
